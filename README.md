Sistema de Pedidos - QUERCUS

Sistema web para la gestión de pedidos desarrollado como proyecto académico/profesional, enfocado en la administración de clientes, productos y órdenes dentro de un flujo completo de negocio.

Aplicación diseñada para gestionar pedidos de forma eficiente, permitiendo:

Gestión de productos
Creación y seguimiento de pedidos
Control del estado de las órdenes

El sistema simula un entorno real de negocio donde se centraliza la información y se optimiza el proceso de ventas.

Flujo del sistema
1. Se registran pedidos en el sistema
2. Se gestionan productos disponibles
3. Se agregan productos al pedido
4. Se calcula el total
5. Se guarda el pedido en la base de datos
6. Se cancela el pedido e imprime tiquete

Tecnologías utilizadas
C#, JS, HTMl, CSS, SQL, ASP.NET Entity Framework.
